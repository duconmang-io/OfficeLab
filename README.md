# officelab.duconmang.io.vn

Trang giới thiệu OfficeLAB: một trang HTML tĩnh (`index.html` + `assets/`), không cần build, được xuất bản bằng GitHub Pages từ nhánh `main`.

- Phông chữ: Bricolage Grotesque và Be Vietnam Pro (Google Fonts, SIL OFL).
- Ảnh chụp màn hình là ảnh thật của OfficeLAB 1.5.0.
- Tên miền tùy chỉnh khai báo trong tệp `CNAME`.

Sửa nội dung: chỉnh `index.html`, commit và push lên `main`; GitHub Pages tự cập nhật sau khoảng 1 phút.
